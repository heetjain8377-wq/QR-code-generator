# QR Code Generator

A simple, responsive QR Code Generator that converts URLs into QR codes using the QR Server API.

## 🚀 Live Demo

[Try the QR Code Generator](https://qrcodegeneratorapiapp.netlify.app)

## ✨ Features

- Generate QR codes from valid URLs
- Input validation for empty and invalid URLs
- Download generated QR codes as PNG images
- Loading indicator while the QR code is generated
- Responsive layout for mobile and desktop
- Generate QR codes by clicking the button or pressing Enter

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- [QR Server API](https://goqr.me/api/)

## 📸 How to Use

1. Open the live demo.
2. Click **Generate QR** or press Enter.
3. Scan the generated QR code with your phone.
4. Click **Download QR Code** to save the image.

## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/heetjain8377-wq/QR-code-generator.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No package installation is required.
